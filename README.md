# TRAFFIC-LIGHT-CONTROLLER-USING-VERILOG-HDL

A clock-driven **Finite State Machine (FSM)-based Traffic Light Controller** designed in Verilog HDL to control traffic signals across multiple roads and directions.

## Features

* Implements a **6-state FSM** for sequential traffic signal control.
* Controls **red, yellow, and green signals** for multiple traffic directions.
* Uses a **clock-driven counter** to maintain each traffic-light state for a predefined duration.
* Supports **asynchronous reset** to initialize the controller to its starting state.
* Provides coordinated transitions between traffic signals to prevent conflicting green signals.
* Includes a **Verilog testbench** for verifying reset operation, state transitions, timing, and output behavior.

## Concepts Used

* Finite State Machines (FSM)
* Sequential Logic
* Clocked Counters
* Asynchronous Reset
* State-Based Output Control
* RTL Design
* Verilog HDL
